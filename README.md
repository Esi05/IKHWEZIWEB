# IKHWEZI Hair Care Products

## 1. Project Overview

IKHWEZI Hair Care Products is a website developed for a natural hair-care products business. The purpose of the website is to provide customers with information about the business, its natural hair-care products, and ways to contact the business.

The website provides a simple and user-friendly platform where customers can learn more about IKHWEZI Hair Care Products, view available products, contact the business, and complete a hair consultation form.

---

## 2. Project Objectives

The main objectives of the website are to:

- Introduce customers to IKHWEZI Hair Care Products.
- Display the available natural hair-care products.
- Provide information about the business.
- Provide contact information for customers.
- Allow customers to send messages through a contact form.
- Allow customers to complete a hair consultation.
- Create a simple, attractive and user-friendly website.
- Demonstrate the use of HTML and CSS in website development.

---

## 3. Target Audience

The target audience for IKHWEZI Hair Care Products includes:

- People interested in natural hair-care products.
- Customers looking for hair-care products.
- People experiencing common hair-care concerns such as dry scalp, dandruff and hair breakage.
- Existing customers who need to contact the business.
- Potential customers who want to learn more about IKHWEZI products.

---

## 4. Technologies Used

The website was developed using the following technologies:

- **HTML5** – used to structure the content and pages of the website.
- **CSS3** – used to style the website and improve its visual presentation.
- **Visual Studio Code** – used as the development environment.
- **GitHub** – used for version control and hosting the project.
- **Google Maps** – used to display the business location.

## Responsive Design

Media queries are used to make the website responsive on different screen sizes.

### Desktop

The website uses multi-column layouts and horizontal navigation on larger screens.

### Tablet

At screens below 768px:

- Navigation becomes more flexible
- Cards use fewer columns
- Content spacing is reduced
- Sections adjust to fit smaller screens

### Mobile

At screens below 480px:

- Navigation becomes vertical
- Cards use a single-column layout
- Images are resized
- Font sizes are reduced
- Form fields become easier to use on small screens

## Interactive Features

Pseudo-classes are used to improve user interaction.

Examples include:

- `:hover` for navigation links, cards and buttons
- `:focus` for form fields and links
- `:active` for buttons

Transitions are also used to create smooth visual effects.

# IKHWEZI Hair Care Products Website
## POE Part 3 – Website Development Documentation

### 1. Project Overview

IKHWEZI Hair Care Products is a website developed to promote natural hair care products and provide customers with information about the brand, its products and available hair consultation services.

The purpose of this project is to create a professional, user-friendly and responsive website that allows customers to explore the product range, learn about the business and contact the company for enquiries.

### 2. Project Objectives

The main objectives of the project are to:

- Develop a functional and visually appealing hair care website.
- Present the company's background, mission, vision and values.
- Display hair care products with images and descriptions.
- Provide contact and hair consultation forms.
- Use JavaScript to improve interactivity and form validation.
- Implement interactive website features, including image lightboxes and an interactive map where applicable.
- Create a responsive layout for desktop, tablet and mobile devices.
- Publish the website online using Netlify.
- Use GitHub for source-code management and version control.

### 3. Target Audience

The target audience includes people interested in hair care products, individuals looking for hair care information and customers who want to contact IKHWEZI for product enquiries or hair consultations.

### 4. Website Pages

The website consists of the following pages:

- **Home (`index.html`):** Introduces IKHWEZI Hair Care Products and provides an overview of the brand.
- **About (`about.html`):** Explains the company's story, mission, vision and values.
- **Products (`products.html`):** Displays the available hair care products and their descriptions.
- **Contact (`contact.html`):** Provides contact information and a form for customer enquiries.
- **Hair Consultation (`consultation.html`):** Allows visitors to submit information and enquiries relating to hair consultations.

### 5. Technologies Used

- **HTML5:** Used to structure the website content.
- **CSS3:** Used for styling, colours, layouts, animations, hover effects and responsive design.
- **JavaScript:** Used to add interactive features, validate forms and improve the user experience.
- **Visual Studio Code:** Used to write and edit the website code.
- **Git and GitHub:** Used to track changes and maintain the project source code.
- **Netlify:** Used to host and publish the website online.
- **Web3Forms:** Used to process form submissions if configured and tested successfully.
- **Google Maps or Leaflet.js:** Used to provide an interactive map if implemented in the final website.

### 6. JavaScript Functionality

JavaScript is used to make the website more interactive and user-friendly. Depending on the features implemented in the final version, the functionality includes:

- **Form validation:** Checks required fields and helps users correct invalid or missing information before submission.
- **Form submission:** Sends customer enquiries through the configured form service when the service is correctly connected.
- **Image lightbox:** Allows users to click supported images to view them in an enlarged display.
- **Navigation interaction:** Supports interactive navigation features where implemented.
- **Interactive map:** Helps visitors view the selected business location when a map has been integrated.

These features should be tested in the deployed website to confirm that they work correctly.

### 7. Website Design and Responsiveness

The website uses a consistent visual identity inspired by the IKHWEZI brand. The design includes a coordinated colour scheme, readable typography, product images, navigation links, content sections and styled forms.

CSS Flexbox and Grid are used where appropriate to organise content. Media queries help adapt the layout to different screen sizes.

Responsive design considerations include:

- Navigation that remains usable on smaller screens.
- Images that resize to fit their containers.
- Product cards that adapt to available screen space.
- Readable text and appropriate spacing.
- Forms that are easy to use on mobile devices.
