# IKHWEZI Hair Care Products

## 1. Project Overview

IKHWEZI Hair Care Products is a website developed for a natural hair-care products business. The purpose of the website is to provide customers with information about the business, its natural hair-care products, and ways to contact the business.

The website provides a simple and user-friendly platform where customers can learn more about IKHWEZI Hair Care Products, view available products, contact the business, and complete a hair consultation form.

---

## 2. Project Objectives

The main objectives of the website are to:

- Introduce customers to IKHWEZI Hair Care Products.
- Display the available natural hair-care products.
- Provide information about the business.
- Provide contact information for customers.
- Allow customers to send messages through a contact form.
- Allow customers to complete a hair consultation.
- Create a simple, attractive and user-friendly website.
- Demonstrate the use of HTML and CSS in website development.

---

## 3. Target Audience

The target audience for IKHWEZI Hair Care Products includes:

- People interested in natural hair-care products.
- Customers looking for hair-care products.
- People experiencing common hair-care concerns such as dry scalp, dandruff and hair breakage.
- Existing customers who need to contact the business.
- Potential customers who want to learn more about IKHWEZI products.

---

## 4. Technologies Used

The website was developed using the following technologies:

- **HTML5** – used to structure the content and pages of the website.
- **CSS3** – used to style the website and improve its visual presentation.
- **Visual Studio Code** – used as the development environment.
- **GitHub** – used for version control and hosting the project.
- **Google Maps** – used to display the business location.

---

## 5. Website Pages

The website consists of the following pages:

| Page | Description |
|------|-------------|
| Home | Introduces IKHWEZI Hair Care Products and highlights the business. |
| About | Provides information about the business, its story, mission, vision and values. |
| Products | Displays the different IKHWEZI hair-care products. |
| Contact | Provides contact details, location information and a contact form. |
| Hair Consultation | Allows users to provide information about their hair type and hair-care concerns. |

---

## 6. Website Features

### Home Page

The Home page introduces the IKHWEZI Hair Care Products brand and provides information about natural hair care.

The page includes:

- Welcome message
- Hero section
- Hair-care benefits
- Navigation menu
- Footer

### About Page

The About page provides information about the business.

It includes:

- Our Story
- Our Mission
- Our Vision
- Our Values
- Why Choose IKHWEZI?

### Products Page

The Products page displays the available IKHWEZI products.

The products include:

- IKHWEZI Hair Oil
- IKHWEZI Hair Food
- IKHWEZI Hair Spray
- IKHWEZI Shampoo
- IKHWEZI Conditioner

### Contact Page

The Contact page allows users to find information about the business.

It includes:

- Business name
- Location
- Telephone number
- Email address
- Google Maps location
- Contact form

### Hair Consultation Page

The Hair Consultation page allows users to provide information about their hair.

The form includes:

- Full name
- Email address
- Phone number
- Hair type
- Hair concerns
- Submit button
